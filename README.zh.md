FTP Sync 是 Notepad++ 的 FTP / FTPES / SFTP 客户端：服务器树、直接在服务器上打开和保存文件、日志、传输队列，以及防止覆盖他人修改的保护。在保存之前以及后台，插件会将打开的文件与服务器上的副本比较；如果服务器上的文件已更改，会显示差异并提供合并。任何内容都不会被悄悄覆盖，文件的所有版本都保存在备份中。无需其他插件。

## 安装

1. 需要 Notepad++（64 位；32 位请使用 `x86` zip）和 .NET Framework 4.x（Windows 10/11 已自带）。
2. 解压 zip，得到 `...\Notepad++\plugins\FtpSync\FtpSync.dll`（旁边是 `FtpSync.Managed.dll`、`Renci.SshNet.dll` 和 `lang` 文件夹）。
3. 如果 Windows 将文件标记为已下载：右键每个文件 → 属性 → “解除锁定”（或运行 `Get-ChildItem -Recurse | Unblock-File`）。
4. 重启 Notepad++。菜单 **插件 → FTP Sync**。

可以在设置中从 FileZilla (XML/CSV) 或 NppFTP 导入配置文件。

## 语言

界面支持多语言：俄语（内置）、English、Українська、Deutsch、Español、Français、中文。默认跟随 Windows 语言，也可在“配置文件和设置”→“界面语言”中手动选择（更改后重启 Notepad++）。

添加自己的语言：将 `lang\_template.txt` 复制为 `lang\xx.txt`（xx 为语言代码，例如 `it`），在第一行写 `#name: Italiano`，并翻译右侧一列（格式 `键<TAB>译文`，`\n` 表示换行，保留 `{0}` `{1}`）。未翻译的内容以俄语显示。该语言会自动出现在列表中。

## 连接树（右侧）

安装后右侧会出现“FTP Sync - 连接”面板（如果关闭了：插件 → FTP Sync →“显示连接树”，或点工具栏图标）。

* 配置文件树。双击配置文件即连接；会立即打开您的文件夹：路径 `/ › home › … › 您的文件夹`，没有多余的相邻文件夹，只显示您文件夹的内容。起始文件夹：您在此账户上最后工作的文件夹（保存在配置文件中），否则是配置文件中设置的，否则是服务器的主目录。要查看路径上任一文件夹的完整列表，选中它并按 F5。
* 展开文件夹或双击打开文件时，树会自动滚动，使所选项位于树窗口中央（垂直和水平方向）。如果在文件夹加载期间您使用了滚轮、滚动条或按了键，自动滚动不会干预。
* 文件夹在展开时加载。隐藏文件（`.cache`、`.htaccess`）可见（可在配置文件中关闭）。
* 无文字的图标区分文件类型：PHP、JS、TS、CSS、HTML、JSON、XML、MD/TXT/LOG、图片、压缩包、SQL、设置（`.ini/.conf/.htaccess/.env/.yml`）、脚本（`.sh/.bat`）、PDF、音频/视频。备份树和文件状态列表使用相同的图标。
* 双击文件：下载到本地缓存并在标签页中打开。如果本地副本不同且从未上传，插件会询问如何处理。
* 保存本地缓存中的文件时，会自动上传到服务器（可在配置文件中关闭）。写入服务器之前，服务器上的原版本会存入备份。
* 右键：打开、刷新 (F5)、上传文件、将文件夹下载到缓存、新建文件夹/文件、重命名 (F2)、删除（Del；被删除文件的副本会保存到备份）、复制路径、“此文件的备份”。
* 将文件或文件夹从资源管理器拖到树中的文件夹上即可上传。
* 树上方的路径栏：输入路径并按 Enter 跳转。
* 底部有一行简短的状态：正在进行的传输及百分比（上传为 `⬆ main.css 45%`，下载为 `⬇`，另有细进度条）、`✔ 完成`，或 `✖ 上传/下载/连接错误：…`。点击该行或 `≡` 按钮打开完整日志。`■` 按钮停止队列。

## 日志

底部面板，“日志”标签页：记录颜色：**绿色** - 完成，**橙色** - 上传，**红色** - 错误，棕色 - 警告，黑色 - 普通消息。有按颜色筛选。所有事件都会记录（连接、下载、上传、检查、错误）。最后一行始终可见（自动滚动）。带 `▸` 的行含有详情：选中该行并点“展开”（或双击）即可阅读完整错误文本；“复制”会把记录连同详情放入剪贴板。“日志”标签页是无按钮的简易日志；“详细日志”标签页是带按钮（展开、复制、清除、日志文件）、颜色筛选、搜索和自动滚动的同一份日志。完整日志写入 `plugins\Config\FtpSync\log.txt`（“日志文件”按钮）。

## 功能

| 功能 | 工作方式 |
|---|---|
| 保存时警告 | 写入文件前，将服务器与您加载的内容比较。如果服务器已更改，会显示带差异的窗口：**自动合并**、**采用服务器版本**（您的文本进入新标签页和备份）、**覆盖服务器**。关闭窗口是安全的选择。 |
| 后台检查 | 打开文件时、切换标签页时、返回 Notepad++ 窗口时，以及按定时器（默认 60 秒）。显示带差异的“文件在服务器上已更改”窗口。 |
| 文件的三个版本 | 保留“基准”（您加载的版本），因此知道谁改了什么，并能进行三路合并 (diff3)。 |
| 按同样路径的备份 | 插件看到的每个版本（服务器的、保存时您的、覆盖前、上传前）都会复制到 `…\FtpSync\Backups\<配置文件>\<服务器路径>\<文件>\<日期_原因>.<扩展名>`。面板中的树与站点结构一致。相同内容不会重复保存。 |
| 面板 | 插件 → FTP Sync →“显示面板”：“文件状态”和“备份”标签页（树、筛选、“当前文件”）。“清理备份…”按钮可删除所有备份、超过 30 天的备份，或除每个文件最新 3 个版本之外的全部；“备份文件夹”在资源管理器中打开该文件夹；树中文件夹的右键菜单有“打开文件夹”和“清理此文件夹…”。按版本：打开副本、与服务器/编辑器比较、还原到编辑器、上传到服务器、在资源管理器中显示、删除。 |
| 从 NppFTP 导入 | 可选：从 `NppFTP.xml` 读取配置文件、缓存路径和文件夹对应关系。密码会被解密（NppFTP 使用 DES 和默认密钥 `NppFTP00` 加密）；失败时请手动输入。密码通过 Windows DPAPI 保存。 |
| 从 FileZilla 导入 | 菜单“从 FileZilla 导入配置文件 (XML/CSV)…”（或设置中的按钮）。默认建议 `%APPDATA%\FileZilla\sitemanager.xml`（或 FileZilla“文件 → 导出”的文件）。从 XML 会导入全部内容：站点管理器文件夹（作为树中的分组）、主机、端口、协议（FTP、FTPES、SFTP；HTTP/HTTPS 会跳过）、用户、密码 (base64)、SFTP 密钥文件、被动/主动模式、备注、本地和远程文件夹、书签（导入到配置文件的“书签”菜单和文件夹对应关系）。受 FileZilla 主密码保护的密码无法导入，请手动输入（会显示警告）。也接受 CSV。密码使用 Windows DPAPI 加密并绑定到您的 Windows 账户。导入后请删除含明文密码的文件。 |
| 上传文件 | “将当前文件上传到服务器（带检查）”，适用于文件夹对应关系覆盖的任何文件。 |
| 诊断 | “关于插件 / 诊断”显示当前文件属于哪个配置文件和服务器路径。 |

协议：FTP、FTPES（显式 TLS）、SFTP（密码或密钥；SFTP 连接保持打开，比 FTP 更快）。不支持隐式 FTPS（端口 990）。

## 插件如何判断文件属于哪个服务器

* 从树中打开的文件位于配置文件的本地缓存中，插件知道它们的服务器路径。
* 对于缓存之外的文件（例如您自己的站点文件夹），请在“配置文件和设置”中添加“本地文件夹 - 服务器文件夹”的对应关系。如果诊断显示文件“不属于任何配置文件”，请添加这样的对应关系。
* 比较时忽略换行符和 BOM 的差异。
* 如果同时安装了 NppFTP，请在其配置文件中关闭保存时上传，或在 FTP Sync 配置文件中关闭“保存时上传到服务器”：否则两个插件都会上传该文件。

## 构建

Linux：`mono-mcs`、`mono-devel`、`mingw-w64`、`g++-mingw-w64-i686`、`zip`。`./build.sh` 会运行核心测试（diff/merge、NppFTP / FileZilla XML / CSV 导入、语言文件、备份、检查逻辑），构建托管部分和两个原生外壳 (x64/x86)，并将压缩包（含 `lang` 文件夹）放入 `dist/`。

结构：一个小型原生 DLL (`native/FtpSync.cpp`) 导出 Notepad++ 函数并承载 .NET Framework 4；所有逻辑和界面 (WinForms) 都在 `FtpSync.Managed.dll` 中。

## 状态

核心（比较、合并、备份、导入、FTP 列表解析、传输队列）有自动化测试覆盖；FTP/SFTP 客户端尚未对真实服务器测试。与 Notepad++ 的集成（窗口、停靠、消息）依据 API 文档构建，但尚未在真实的 Notepad++ 中运行。如果有异常表现，请查看 `…\plugins\Config\FtpSync\log.txt` 并发送给我们。
