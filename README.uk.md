FTP Sync - FTP / FTPES / SFTP-клієнт для Notepad++: дерево серверів, відкриття та збереження файлів просто на сервері, журнал, черга передач і захист від перезапису чужих правок. Перед збереженням і у фоні плагін звіряє відкритий файл із копією на сервері; якщо файл на сервері змінили, показує відмінності й пропонує злиття. Нічого не перезаписується мовчки, а всі версії файлів зберігаються в бекапах. Інші плагіни для роботи не потрібні.

## Встановлення

1. Потрібен Notepad++ (64-біт; для 32-біт візьміть zip `x86`) і .NET Framework 4.x (є у Windows 10/11).
2. Розпакуйте zip так, щоб вийшло `...\Notepad++\plugins\FtpSync\FtpSync.dll` (поруч `FtpSync.Managed.dll`, `Renci.SshNet.dll` і папка `lang`).
3. Якщо Windows позначила файли як завантажені: ПКМ по кожному файлу → Властивості → «Розблокувати» (або `Get-ChildItem -Recurse | Unblock-File`).
4. Перезапустіть Notepad++. Меню **Плагіни → FTP Sync**.

Профілі можна перенести з FileZilla (XML/CSV) або NppFTP у налаштуваннях.

## Мови

Інтерфейс багатомовний: російська (вбудована), English, Українська, Deutsch, Español, Français, 中文. Мова вибирається автоматично за мовою Windows або вручну: «Профілі та налаштування» → «Мова інтерфейсу» (після зміни перезапустіть Notepad++).

Додати свою мову: скопіюйте `lang\_template.txt` у `lang\xx.txt` (xx - код мови, наприклад `it`), першим рядком напишіть `#name: Italiano` і перекладіть праву колонку (формат `ключ<TAB>переклад`, `\n` - новий рядок, `{0}` `{1}` зберігайте). Неперекладене показується російською. Мова з'явиться в списку сама.

## Дерево підключень (праворуч)

Після встановлення праворуч з'являється панель «FTP Sync - підключення» (якщо закрили: Плагіни → FTP Sync → «Показати дерево підключень» або іконка на панелі інструментів).

* Дерево профілів. Подвійний клік по профілю = підключення; одразу відкривається ваша папка: шлях `/ › home › … › ваша папка` без зайвих сусідів, вміст лише вашої папки. Стартова папка: остання, де ви працювали на цьому акаунті (запам'ятовується в профілі), інакше задана в профілі, інакше домашня папка сервера. Щоб побачити повний список будь-якої папки на шляху, виділіть її й натисніть F5.
* Під час розгортання папки та відкриття файлу подвійним кліком дерево саме прокручується так, щоб вибраний елемент опинився в центрі вікна (по вертикалі й по горизонталі). Якщо ви крутите колесо, смугу прокручування або натискаєте клавішу, поки папка вантажиться, автопрокручування не заважає.
* Папки підвантажуються в міру розгортання. Приховані файли (`.cache`, `.htaccess`) видно (можна вимкнути в профілі).
* Іконки без підписів розрізняють типи файлів: PHP, JS, TS, CSS, HTML, JSON, XML, MD/TXT/LOG, зображення, архіви, SQL, налаштування (`.ini/.conf/.htaccess/.env/.yml`), скрипти (`.sh/.bat`), PDF, аудіо/відео. Ті самі іконки в дереві бекапів і в списку статусу файлів.
* Подвійний клік по файлу: він завантажується в локальний кеш і відкривається у вкладці. Якщо локальна копія відрізняється й не була викладена, плагін запитає, що робити.
* Під час збереження файлу з локального кешу він сам викладається на сервер (можна вимкнути в профілі). Перед записом на сервер попередня серверна версія потрапляє в бекапи.
* Правий клік: відкрити, оновити (F5), викласти файли, завантажити папку в кеш, нова папка/файл, перейменувати (F2), видалити (Del; копії видалених файлів зберігаються в бекапи), скопіювати шлях, «Бекапи цього файлу».
* Перетягніть файли або папки з Провідника на папку в дереві, щоб викласти.
* Рядок шляху над деревом: введіть шлях і Enter, щоб перейти.
* Унизу один короткий рядок стану: передача з відсотками (`⬆ main.css 45%` для викладання, `⬇` для завантаження, плюс тонка смужка), `✔ готово` або `✖ Помилка викладання/завантаження/підключення: …`. Клік по рядку або кнопка `≡` відкриває повний журнал. Кнопка `■` зупиняє чергу.

## Журнал

Нижня панель, вкладка «Журнал»: кольори записів: **зелений** - готово, **помаранчевий** - викладання, **червоний** - помилка, коричневий - попередження, чорний - звичайне повідомлення. Є фільтр за кольором. Журналюються всі події (підключення, завантаження, викладання, перевірки, помилки). Останній рядок видно одразу (автопрокручування). Рядки з `▸` мають подробиці: виберіть рядок і натисніть «Розгорнути» (або подвійний клік), щоб прочитати повний текст помилки; «Копіювати» кладе запис із подробицями в буфер. Вкладка «Журнал» - простий журнал без кнопок; вкладка «Розширений журнал» - той самий журнал із кнопками (розгорнути, копіювати, очистити, файл журналу), фільтром за кольором, пошуком і автопрокручуванням. Повний журнал пишеться у файл `plugins\Config\FtpSync\log.txt` (кнопка «Файл журналу»).

## Можливості

| Функція | Як працює |
|---|---|
| Попередження під час збереження | Перед записом файлу порівнює сервер із тим, що ви завантажили. Якщо сервер змінився, вікно з відмінностями: **авто-злиття**, **взяти серверну** (ваш текст іде в нову вкладку й у бекап), **перезаписати сервер**. Закриття вікна = безпечний варіант. |
| Фонова перевірка | Під час відкриття файлу, перемикання вкладки, повернення у вікно Notepad++ і за таймером (за замовчуванням 60 с). Показує вікно «файл змінено на сервері» з відмінностями. |
| Три версії файлу | Зберігає «базу» (те, що ви завантажили), тому розуміє, хто що змінив, і вміє тристороннє злиття (diff3). |
| Бекапи за тим самим шляхом | Кожна версія, яку плагін побачив (серверна, ваша під час збереження, перед перезаписом, перед викладанням), копіюється в `…\FtpSync\Backups\<профіль>\<шлях на сервері>\<файл>\<дата_причина>.<розширення>`. Дерево в панелі повторює структуру сайту. Однаковий вміст не дублюється. |
| Панель | Плагіни → FTP Sync → «Показати панель»: вкладки «Статус файлів» і «Бекапи» (дерево, фільтр, «поточний файл»). Кнопка «Очистити бекапи…» видаляє всі бекапи, старші за 30 днів або все, крім 3 останніх версій кожного файлу; «Папка бекапів» відкриває папку в Провіднику; у меню папки в дереві є «Відкрити папку» та «Очистити цю папку…». По версії: відкрити копію, порівняти із сервером / редактором, відновити в редактор, викласти на сервер, показати в Провіднику, видалити. |
| Імпорт з NppFTP | За бажанням: профілі, шляхи кешу й відповідність папок читаються з `NppFTP.xml`. Пароль розшифровується (NppFTP шифрує його DES із ключем за замовчуванням `NppFTP00`); якщо не вийде, введіть вручну. Паролі зберігаються через Windows DPAPI. |
| Імпорт з FileZilla | Меню «Імпорт профілів із FileZilla (XML/CSV)…» (або кнопка в налаштуваннях). За замовчуванням пропонується `%APPDATA%\FileZilla\sitemanager.xml` (або файл із «Файл → Експорт» FileZilla). З XML переноситься все: папки менеджера сайтів (у дерево як групи), хост, порт, протокол (FTP, FTPES, SFTP; HTTP/HTTPS пропускаються), логін, пароль (base64), файл ключа SFTP, пасивний/активний режим, коментар, локальна й віддалена папка, закладки (в меню «Закладки» профілю й у відповідність папок). Паролі під майстер-паролем FileZilla імпортувати не можна - введіть вручну (буде попередження). Також приймається CSV. Паролі шифруються Windows DPAPI і прив'язані до вашого облікового запису Windows. Після імпорту видаліть файл із відкритими паролями. |
| Викласти файл | «Викласти поточний файл на сервер (з перевіркою)» для будь-якого файлу з відповідності папок. |
| Діагностика | «Про плагін / діагностика» показує, до якого профілю й шляху на сервері належить поточний файл. |

Протоколи: FTP, FTPES (явний TLS), SFTP (пароль або ключ; SFTP-з'єднання тримається відкритим, швидше за FTP). Неявний FTPS (порт 990) не підтримується.

## Як плагін визначає, до якого сервера належить файл

* Файли, відкриті з дерева, лежать у локальному кеші профілю, і плагін знає їхній шлях на сервері.
* Для файлів поза кешем (наприклад, ваша папка із сайтом) додайте відповідність «локальна папка - папка на сервері» в «Профілі та налаштування». Якщо діагностика каже, що файл «не належить жодному профілю», додайте таку відповідність.
* Порівняння ігнорує різницю в кінцях рядків і BOM.
* Якщо встановлено NppFTP, вимкніть у його профілі викладання під час збереження або в профілі FTP Sync «Викладати на сервер під час збереження»: інакше файл викладуть обидва плагіни.

## Збирання

Linux: `mono-mcs`, `mono-devel`, `mingw-w64`, `g++-mingw-w64-i686`, `zip`. `./build.sh` проганяє тести ядра (diff/merge, імпорт NppFTP / FileZilla XML / CSV, мовні файли, бекапи, логіка перевірки), збирає керовану частину та два нативні шими (x64/x86) і кладе архіви (з папкою `lang`) у `dist/`.

Будова: маленька нативна DLL (`native/FtpSync.cpp`) експортує функції Notepad++ і піднімає .NET Framework 4, а вся логіка та інтерфейс (WinForms) у `FtpSync.Managed.dll`.

## Стан

Ядро (порівняння, злиття, бекапи, імпорт, розбір списків FTP, черга передач) покрито автотестами; клієнти FTP/SFTP із живим сервером не перевірялись. Інтеграція з Notepad++ (вікна, докінг, повідомлення) зібрана за документацією API, але в живому Notepad++ ще не запускалась. Якщо щось поводиться дивно, дивіться `…\plugins\Config\FtpSync\log.txt` і надішліть його.
